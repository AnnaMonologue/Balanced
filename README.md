# 平衡器

## 项目简介

平衡器是一个面向接稿个体户、学生党、创作者和自由职业者的本地生活工作记录台。它把常规番茄钟计时、今日待办、生活记录、接稿排单、长期规划、历史手账和统计图表放在一个本地 HTML 应用里，优先保证个人可用、数据可控、打开即用。

当前版本的主入口是：

```text
frontend/index.html
```

原始单文件版本保留在本地开发目录中，GitHub 展示版只同步整理后的前端入口和资源文件。

## 已完成的主要功能

1. 今日打卡

- 显示当天日期。
- 支持日间/夜间主题切换，主题偏好保存到 `localStorage`。
- 显示学习总时长和拉磨总时长。
- 支持上午、下午、晚间三段上工打卡，每段记录上班和下班时间。
- 支持睡眠记录：记录入睡、醒来、睡眠累计时长。
- 支持摸鱼耗时记录：开始/结束计时，结束时保存文字说明和耗时日志。
- 支持拉磨耗时记录：开始/结束计时，结束时保存文字说明和耗时日志。
- 支持四类自定义计时：阅读、上课、论文、运动。每类可开始/暂停计时，可填写文本记录，计时分类名称可编辑。
- 支持今日待办：新增、勾选完成、删除，并显示完成数。

2. 生活记录

- 干饭记录：输入餐食或饮食内容，按时间保存。
- 洗漱记录：通过快捷按钮记录刷牙、洗澡、洗头、护肤。
- 财务记录：记录收入/支出，并区分二次和三次。
- 自动计算今日花费和今日收入。

3. 未来规划和排单

- 学习长线规划：课程相关、项目计划。
- 同人创作规划：接稿排单、为爱发电。
- 接稿排单字段包括单主、单名、节点、价格、备注、日期、完成状态。
- 排单完成后，如果有价格，可选择自动记入今日二次收入。
- 支持未完成/已完成切换查看。
- 支持自动时间线，把学习 DDL 放左侧，把同人/接稿 DDL 放右侧，并显示距离日期的状态。

4. 历史手账

- 自动按日期读取历史数据。
- 展示某日学习、运动、摸鱼、拉磨、睡眠、收支、待办、生活记录。
- 用饼图展示当日睡眠、学习、运动、摸鱼、拉磨的时间占比。

5. 数据统计

- 支持最近 7 天、30 天、90 天统计。
- 汇总睡眠、学习、运动、拉磨、完成任务、收入、支出。
- 用 Chart.js 绘制精力分布、任务完成、二次/三次收支图表。

6. 本地备份和同步

- 支持导出本应用的 `merged_` 前缀数据为 JSON。
- 支持从 JSON 备份导入并覆盖本地数据。
- 支持同步设置弹窗。
- 同步口令只保存在会话中；同步设置保存在 `localStorage`。
- 使用 Web Crypto API：PBKDF2-SHA256 派生密钥，AES-GCM 加密数据包。
- 后端只保存密文，不保存明文记录和同步口令。
- 当前前端已配置远端同步接口 `PUT /sync/:syncCode` 和 `GET /sync/:syncCode` 的调用方式。

## 如何运行

### 只使用本地前端

直接双击打开：

```text
frontend/index.html
```

这个模式下，主要数据保存在浏览器的 `localStorage` 里。换浏览器、清理浏览器数据、隐私模式关闭后，数据可能丢失，所以建议定期使用导出备份。

### 使用同步后端

后端将在下一阶段补充，目前 GitHub 版先保留前端和产品/架构文档。前端已经预留下面两个接口：

```text
PUT /sync/:syncCode
GET /sync/:syncCode
```

后端只需要保存加密后的 JSON 包，不需要理解业务数据。当前 `SYNC_API_BASE` 留空，因此同步功能会使用本机模拟云端密文，不会连接真实服务器。

## 技术栈

- 前端：HTML、CSS、原生 JavaScript。
- 样式：Tailwind CSS CDN、自定义 CSS 变量、Font Awesome 4.7。
- 图表：Chart.js。
- 本地存储：localStorage、sessionStorage。
- 加密：浏览器 Web Crypto API，PBKDF2-SHA256 + AES-GCM。
- 同步后端：Cloudflare Worker 或轻量 Windows PowerShell HTTP 服务。

## 使用建议

- 日常使用时优先打开 `frontend/index.html`。
- 修改功能前，先对照 `ARCHITECTURE.md` 里的模块边界。
- 真正上线以前，需要完成的端到端测试内容：新增记录、刷新页面、导出备份、导入备份、生成加密备份、换浏览器恢复。
